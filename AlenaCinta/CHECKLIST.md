# ✅ Pre-Deployment Checklist

Before deploying, make sure:

- [ ] Code is pushed to GitHub (or GitLab/Bitbucket)
- [ ] You have an account on Render or Railway
- [ ] `package.json` has `build` and `start` scripts (✅ already done)
- [ ] All dependencies are listed in `package.json` (✅ already done)

## What Happens During Deployment:

1. Platform clones your GitHub repo
2. Runs `npm install` (installs dependencies)
3. Runs `npm run build` (builds frontend + backend)
4. Runs `npm start` (starts the server)
5. Your site is live! 🚀
